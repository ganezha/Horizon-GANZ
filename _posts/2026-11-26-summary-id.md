### [Google dilaporkan akan mewajibkan penggunaan server MCP miliknya untuk agen Workspace; server MCP Gmail tidak bisa mengirim email](https://techstackups.com/articles/google-workspace-ai-agents-mcp/) ⭐️ 7.0/10

TechStackUps melaporkan bahwa Google akan mewajibkan agen AI yang mengakses Workspace untuk menggunakan server Model Context Protocol \(MCP\) miliknya dan bahwa server MCP Gmail tidak mendukung pengiriman email. Keterbatasan itu berlaku untuk pengiriman lewat server MCP Gmail, bukan untuk semua cara agen mengirim email. Teks lengkap artikel tidak disertakan, sehingga belum jelas agen mana saja yang akan terkena kewajiban itu atau mengapa fitur kirim tidak tersedia.

hackernews · ritzaco · Nov 26, 09:44 · [Diskusi](https://news.ycombinator.com/item?id=50653477)

**「Latar belakang」** Cuplikan pengumuman resmi Google mengonfirmasi bahwa server MCP Workspace sudah tersedia secara umum, tetapi tidak mengonfirmasi adanya kewajiban untuk menggunakannya atau cakupan kewajiban tersebut. Dokumentasi Gmail menjelaskan bahwa server MCP Workspace dapat meminta persetujuan lewat formulir konfirmasi pengguna \(form elicitation\) sebelum agen menjalankan tindakan sensitif. Mekanisme persetujuan itu tidak dengan sendirinya membuat fitur kirim tersedia.

**「Dampak bagi pengembang」** Pengembang yang membuat alur kerja pengiriman email tidak bisa mengandalkan server MCP Gmail selama fitur kirim belum tersedia. Jika kewajiban yang dilaporkan itu diberlakukan, pengembang perlu memeriksa apakah integrasi mereka termasuk dalam cakupannya.

**「Diskusi komunitas」** Perdy mengusulkan agar fitur kirim menggunakan mekanisme elicitation di MCP: server dapat menjeda proses pengiriman dan meminta konfirmasi pengguna sebelum melanjutkan. Schnitz memperkirakan agen akan tetap mengirim email lewat peramban, tetapi dengan alur yang lebih rumit.
